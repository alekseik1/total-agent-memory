1540 вопросов, gpt-4.1-mini-2025-04-14, общий judge. Итоговый прирост +10.45 п.п. включает retrieval и промпт ответа. Исправленный retrieval со старым промптом: 68.44%. Один API-сбой в каждом из двух исправленных прогонов засчитан неправильным ответом.

Mem0 OSS с тем же новым промптом: 71.36%. Парная разница TAM–Mem0 +0.84 п.п., 95% CI [−3.03; +4.96]: преимущество качества не установлено. Локальная медиана retrieval на 200 одинаковых вопросах: TAM context 28.36 ms, Mem0 71.83 ms; p95 66.83/116.16 ms. Это не облачный benchmark и не доказательство места в мировой пятёрке.

Применение:

```json
{"query":"Какую БД выбрал владелец сервиса?","project":"my-project","mode":"context","limit":10,"neighbors":1}
```

Режим добавляет полные соседние записи с источниками; клиенту возвращается `answer_guidance`. Для воспроизведения итоговой QA-строки клиент использует эту инструкцию при генерации. Память сама не генерирует ответ в данном MCP-вызове.

Общий консервативный расход всех прогонов, extraction, диагностик и повторов: **$6.1637292 из $20**. В эту сумму входят сохранённые резервы неопределённых запросов; это не счёт OpenAI.

Изменения разрабатывались на ошибках этого LoCoMo; независимого held-out подтверждения нет. Judge автоматический, человеческая разметка отсутствует. Mem0 использовал локальный Qdrant/FastEmbed без optional spaCy NLP; настройки не эквивалентны Mem0 Cloud. Graphiti/Kuzu не прошёл запуск, Supermemory/MemOS/Letta не получили сопоставимых QA-прогонов.

Проверки кода: 1892 passed, 37 skipped, 126 warnings; wheel собран и проверен вне checkout. Новых lint-замечаний в изменениях нет; существующий lint-долг остаётся. Коммит и деплой не выполнялись.
